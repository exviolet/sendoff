# `web/` — редактор

**Поверхность редактирования Sendoff — SPA на React 19 + TypeScript.**
Продуктовый README, загрузки, демо, список возможностей и справка по клавишам
живут в [корне репозитория](../README.ru.md).

Здесь — табы, workspace'ы, markdown-редактирование, поиск и замена, слэш-меню и
слой персистенса на IndexedDB. Без бэкенда, без API-ключей, без телеметрии: всё
работает на клиенте.

## Чего эта половина не умеет

**Отправка — только на десктопе.** Прямая запись в терминал агента идёт через
Tauri-оболочку из `src-tauri/`. В обычной вкладке браузера `Ctrl+Enter`
деградирует до копирования буфера в клипборд.

По той же причине только на десктопе: нативные файловые диалоги, перетаскивание
файла в редактор, кастомный тайтлбар, живой статус агента и гард
единственного инстанса. Всё остальное — вся поверхность редактирования —
работает в браузере.

Sendoff **desktop-first**; вкладка браузера даёт полноценный редактор без моста
в терминал — именно поэтому `bun dev` годится для работы над UI.

## Быстрый старт

```bash
bun install
bun dev
```

Открыть [http://localhost:5173](http://localhost:5173).

```bash
bun run build      # продакшен-сборка
bun run preview    # отдать продакшен-сборку локально
bun test           # чистая логика + слой IndexedDB
```

> `bun tsc -b`, а не `tsc --noEmit`: корневой `tsconfig.json` — solution-stub с
> `"files": []`, поэтому `--noEmit` проверяет ноль файлов и всегда зелёный.

Чтобы поднять всё десктопное приложение, запусти `bun dev` из корня репозитория —
Tauri сам поставит зависимости и соберёт этот каталог.

## Стек

| Слой | Выбор |
|------|-------|
| Фреймворк | React 19 + TypeScript (strict) |
| Сборка | Vite + Bun |
| Стили | Tailwind CSS v4 |
| Состояние | Zustand |
| Персистенс | IndexedDB (`idb`) |
| Редактор | Нативная `<textarea>` + свой overlay — без Monaco/CodeMirror |
